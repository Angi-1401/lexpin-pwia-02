Text Content

Paragraphs

Semantic HTML elements clearly describe their meaning in a human- and machine-readable way.
Using semantic elements helps with accessibility, SEO, and code readability.

Headings

Headings are used to define the structure of your content. They range from <h1> to <h6>, with <h1> being the most important.

Spans

The <span> element is an inline container used to mark up a part of a text, or a part of a document. It does not inherently represent anything.

Lists

Lists are used to group related items together. There are two main types of lists: unordered and ordered.
